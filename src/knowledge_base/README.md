# AI Transformation Knowledge Base Taxonomy

The engine uses the same A-E indexes for Knowledge Base content and assessment output. Keep new reference documents aligned with `aiTransformation_taxonomy_registry.json`.

## Domains

- A: Adaptive Operating Model
- B: Enterprise AI Architecture & Platform Readiness
- C: AI Strategy, Governance & Value Realization
- D: Data Foundations, Ownership & Accessibility
- E: Business Capability & Service Architecture

## Evidence Categories

Use one or more of the existing evidence categories in document names and front matter:

`Policy`, `Process`, `Operational`, `Automation`, `Accountability`, `Architecture`, `Data`, `Governance`, `Learning`, `Value`.

Reference KB material may guide scoring and recommendations, but must never be treated as customer source evidence.
